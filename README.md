# SKYZR beta

SKYZR is a Streamlit dashboard that replays a fictional hurricane (Hurricane Kestrel) over all 100 North Carolina counties. The scenario is fictional and every report, stock figure and status is synthetic. Only the county boundaries are real public data.

## Run it

Needs Python 3.12 or newer.

```
pip install -r requirements.txt
streamlit run app.py
```

Run the tests with `pytest`.
